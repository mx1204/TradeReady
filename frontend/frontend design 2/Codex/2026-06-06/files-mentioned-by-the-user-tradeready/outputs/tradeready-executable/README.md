# TradeReady Executable Prototype

This folder contains the current runnable UI prototype.

## Run

From PowerShell:

```powershell
.\start-demo.ps1
```

Then open:

```text
http://127.0.0.1:4174
```

## Files

- `index.html` - standalone TradeReady prototype UI
- `start-demo.ps1` - local static server launcher
